# Vector ATC

Локальный авиадиспетчерский симулятор для MSFS 2024 (C# / .NET 8). Цель поставки: один `.exe` без установки.

## Структура

```
VectorAtc.sln
Directory.Build.props              nullable, warnings as errors
src/
  VectorAtc.Core/                  модели, ISimDataSource, разбор запросов (Parsing), шаблоны фраз (Phraseology), автомат диспетчера (Controller), геометрия (Geo)
  VectorAtc.SimLink/               MockSimDataSource + MockScenarios (SimConnect позже)
  VectorAtc.Localization/          ресурсы RU/EN (Strings, Phrases), ILocalizationService, PhraseBook
  VectorAtc.ViewModels/            логика главного окна без WPF (MainViewModel, команды), тестируется без Windows
  VectorAtc.App/                   WPF-оболочка (XAML) и профиль публикации в один .exe
  VectorAtc.Speech/ Ground/ Traffic/   заготовки
tests/
  VectorAtc.Tests/                 xunit
```

## Запуск (Windows, .NET 8 SDK)

```
dotnet build
dotnet test
```

## Сборка одного .exe (без установки)

```
dotnet publish src/VectorAtc.App -p:PublishProfile=SingleExe
```

Готовый файл: `src/VectorAtc.App/bin/publish/VectorATC.exe`. .NET внутри файла, ставить ничего не нужно.
Профиль публикации написан, но ни разу не запускался: в среде разработки нет Windows и пакетов WPF.

## Проверено / не проверено

- Проверено: 78 тестов (локализация, мок, разбор запросов, шаблоны фраз, автомат диспетчера, read-back, очередь, геометрия, логика главного окна) выполнены через минимальную xunit-совместимую заглушку, все проходят. Заглушка падает на заведомо неверном тесте, а две намеренные поломки логики остановки у точки ожидания тестами обнаруживаются.
- Сценарий «запрос руления → клиренс → read-back → удержание у ВПП → передача на Tower → line up and wait» проходит на моке симулятора.
- Ограничения 1c: один самолёт и один аэропорт с маршрутом, заданным вручную; рулёжные дорожки только из одной буквы; суффикс полосы (L/R/C) в read-back не проверяется; разрешение на взлёт не реализовано.
- Не проверено: формулировки шаблонов (особенно русские и US-вариант) не сверены с ICAO Doc 4444, FAA JO 7110.65 и российскими правилами. Это этап 0.
- Не проверено: настоящий `dotnet test` с xunit (пакеты NuGet недоступны в среде разработки), сборка под Windows.
- Окно (XAML) проверено только статически: разметка корректна, все 30 привязок существуют в модели, ресурсы и классы совпадают. Окно ни разу не запускалось.
- Известные недочёты 1d: в демо-режиме статус показывает «Подключено к симулятору», хотя источник данных имитация; замечания о read-back в журнале остаются на английском при русском интерфейсе; подписи строк журнала не меняют язык задним числом.
