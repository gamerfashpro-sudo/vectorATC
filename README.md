# Vector ATC

Локальный авиадиспетчерский симулятор для MSFS 2024 (C# / .NET 8). Цель поставки: один `.exe` без установки.

## Структура

```
VectorAtc.sln
Directory.Build.props              nullable, warnings as errors
src/
  VectorAtc.Core/                  модели, ISimDataSource, разбор запросов (Parsing), шаблоны фраз (Phraseology), автомат диспетчера (Controller),
                                   фазы полёта и объявления салона (Flight), наземное обслуживание (Ground), трафик (Traffic),
                                   проекция карты (Geo), диагностика (Diagnostics), настройки (Settings), интерфейсы речи (Speech)
  VectorAtc.SimLink/               MockSimDataSource (демо) и SimConnectDataSource (реальный симулятор, P/Invoke)
  VectorAtc.Localization/          ресурсы RU/EN (Strings, Phrases), ILocalizationService, PhraseBook
  VectorAtc.ViewModels/            логика главного окна без WPF (MainViewModel), тестируется без Windows
  VectorAtc.App/                   WPF-оболочка (XAML), голос на встроенных средствах Windows, профиль публикации в один .exe
  VectorAtc.Speech/ Ground/ Traffic/   пустые заготовки (код этих частей лежит в Core)
tests/
  VectorAtc.Tests/                 xunit
```

## Запуск (Windows, .NET 8 SDK)

```
dotnet build
dotnet test
```

## Получить .exe, ничего не устанавливая

Готовый `VectorATC.exe` запускается без установки: .NET упакован внутрь файла (около 68 МБ).

Сборка идёт на GitHub Actions при каждом изменении `main`; свежий файл лежит в релизе
**Vector ATC (latest build)** (тег `latest`) на странице Releases. Для версионного релиза создайте тег `v*`
(например, `v0.1.0`): сборка прикрепит `.exe` к нему.

`SimConnect.dll` в файл не входит (права на распространение не подтверждены): при подключении к MSFS приложение берёт её
с компьютера пользователя (рядом с `.exe`, в SDK симулятора). Вкладка «Диагностика» показывает, где она искалась.

Тот же запуск делает настоящий `dotnet test` на Windows.

Собрать вручную (нужен .NET 8 SDK): `dotnet publish src/VectorAtc.App -p:PublishProfile=SingleExe`,
файл появится в `src/VectorAtc.App/bin/publish/VectorATC.exe`.

Отчёт этапа 0 (проверка документации SimConnect, GSX, лицензий, фразеологии): [docs/stage0-report.md](docs/stage0-report.md)

## План и состояние

| Этап | Что | Статус |
|------|-----|--------|
| 1 | Каркас, локализация RU/EN, разбор запросов, автомат Ground/Tower, read-back, окно, демо | готово, окно запускалось у пользователя |
| 2 | SimConnect: подключение, данные самолёта, вкладка диагностики | написано и собирается, **с настоящим MSFS не проверено** |
| 2 | Граф руления из данных аэродрома | не начато (нужен симулятор) |
| 3a | Озвучивание диспетчера и салона (встроенные голоса Windows) | написано, **не слушалось** |
| 3b | Голосовой ввод по кнопке (встроенный распознаватель Windows) | написано, **не проверено на микрофоне**; качество неизвестно |
| 3c | Whisper или другой распознаватель, радиоэффект | не начато (ждёт решения по размеру файла) |
| 4a | Наземное обслуживание: встроенная имитация по таймеру | готово, это модель, не данные симулятора |
| 4b | Интеграция GSX через официальный интерфейс | не начато (ждёт руководство от пользователя) |
| 5a | Трафик: демо-набор вымышленных рейсов, таблица | готово |
| 5b | ИИ-самолёты из MSFS, реальный трафик | не начато (нужен симулятор) |
| 6a | Карта: свой самолёт и трафик, кольца, масштаб | готово, подложки (берега, аэродромы) нет |
| 7a | Фазы полёта и объявления салона RU/EN | готово; границы по абсолютной высоте (допущение) |
| 7b | Delivery/Departure/Approach, настройки | настройки (язык, стиль, позывной, голос, масштаб) готовы; остальное не начато |
| 8 | Публикация: лицензии, атрибуция, версии | не начато |

## Проверено / не проверено

- Проверено: полный набор xunit-тестов проходит в CI на Windows. Логика (разбор запросов, фразы, автомат диспетчера, read-back,
  фазы полёта, объявления, услуги, трафик, проекция карты, сборка диагностики, настройки, модель окна) проверяется тестами,
  ключевые из них проверены намеренными поломками кода.
- Проверено пользователем: окно запускается (дизайн с тех пор переделан и вживую не сверялся).
- Не проверено ни разу: настоящий MSFS (SimConnect, сигнатуры вызовов и раскладка сообщений взяты из документации и не запускались),
  голос и микрофон, внешний вид новых вкладок, имена переменных окружения SDK.
- Ограничения автомата диспетчера: один самолёт и один аэродром (тестовый) с маршрутом руления, заданным вручную; рулёжные дорожки
  только из одной буквы; суффикс полосы (L/R/C) в read-back не проверяется; разрешение на взлёт не реализовано.
- Фразеология: английские ICAO-фразы сверены с CAP 413, часть US-фраз с FAA JO 7110.65 (разделы 3-7, 3-9), два ICAO-шаблона исправлены;
  первоисточники ICAO и российские правила не читались, русские фразы не сверены. Подробности: [docs/phraseology-check.md](docs/phraseology-check.md).
- Трафик в таблице и на карте демонстрационный (вымышленные рейсы), в интерфейсе это написано.
